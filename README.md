# 🌼 Galaxia 3D de Flores Amarillas

Una hermosa galaxia 3D interactiva llena de flores amarillas brillantes. Creada con ❤️ para tu mejor amiga.

## ✨ Características

- **2000 flores amarillas** distribuidas en forma de galaxia espiral
- **Totalmente interactiva:**
  - 🖱️ Arrastra el mouse para rotar la galaxia
  - 🔄 Usa la rueda del mouse para hacer zoom
  - ⏸️ Presiona espacio para pausar/reanudar la animación
- **Efectos visuales increíbles:**
  - Flores brillantes con emisión de luz
  - Iluminación dinámica con múltiples fuentes de luz
  - Fondo de estrellas animado
  - Sombras realistas
  - Animación suave y fluida

## 🚀 Cómo usar

1. Clona este repositorio o descarga los archivos
2. Abre `index.html` en tu navegador web
3. ¡Disfruta de la galaxia de flores!

## 📋 Requisitos

- Un navegador moderno con soporte para WebGL
- Three.js (se carga automáticamente desde CDN)

## 🎮 Controles

| Acción | Control |
|--------|----------|
| Rotar | Arrastra el mouse |
| Zoom | Rueda del mouse arriba/abajo |
| Pausar/Reanudar | Presiona barra espaciadora |

## 🛠️ Tecnologías utilizadas

- **Three.js** - Librería 3D para JavaScript
- **WebGL** - Renderizado gráfico en el navegador
- **HTML5 & CSS3** - Estructura y estilos
